## 1. Introdução

O **Mirame** é uma rede social para apaixonados por filmes e séries. O projeto nasceu no bootcamp da **Laboratoria** como uma SPA (Single Page Application) e vem sendo evoluído para oferecer uma experiência completa de interação, onde usuários podem compartilhar reviews, recomendações e acompanhar as novidades do mundo audiovisual.

---

## 2. Funcionalidades

### 🌟 Novas Atualizações (Versão Atual)

* **Página de Perfil:** Espaço personalizado com foto, bio e histórico de postagens do usuário.
* **Sistema de Comentários:** Agora é possível interagir e debater diretamente em cada postagem.
* **Notificações:** Alertas em tempo real para manter o usuário engajado com a rede.
* **Melhoria de UI/UX:** Refatoração do layout da Home e da Timeline para uma navegação mais fluida.

### ⚙️ Funcionalidades Base

* **Autenticação:** Cadastro e login via e-mail/senha ou Google (Firebase Auth).
* **Timeline:** Feed em tempo real com postagens ordenadas cronologicamente.
* **CRUD de Posts:** Criação, edição e exclusão de publicações.
* **Interações:** Sistema de curtidas (likes).

---

## 3. Tecnologias

O projeto utiliza o ecossistema moderno de JavaScript:

* **Linguagem:** JavaScript (ES6+)
* **Backend & Database:** Firebase v9 (Firestore, Auth, Hosting)
* **Testes:** Jest
* **Ferramentas:** HTML5, CSS3 (Stylelint), SPA Architecture, Git/GitHub
